# Offsite Captain — two-minute demo

Target: 1:55–2:00. Voice direction: confident, warm, brisk, and conversational;
pause briefly after each state change. All inventory and reservations shown are
simulated.

## 0:00–0:12 — The problem

**On screen:** Open on the hosted run sheet, then select **Coordinate offsite**.

**Voiceover:** “Planning a startup offsite looks simple—until travel windows,
meeting dependencies, preparation, venue inventory, and budget all collide.
Offsite Captain turns that mess into one decision-ready run sheet.”

## 0:12–0:37 — Agentic coordination

**On screen:** Show the coordination trace completing, then the repaired plan.

**Voiceover:** “Here, Gemini 3.5 Flash on Vertex AI reads the brief through
bounded Google ADK tools. It finds an arrival-buffer conflict, a double-booked
attendee, and missing preparation work, then repairs the proposal. The model can
read and propose—but it cannot approve or reserve.”

## 0:37–1:02 — Deterministic proof

**On screen:** Move through agenda, owners, inventory, budget, and plan hash.

**Voiceover:** “Deterministic validators own the hard guarantees: attendance,
dependencies, inventory versions, and cost. Every session is feasible, every
preparation task has an owner, and the plan totals seven thousand nine hundred
forty dollars against an eighty-five-hundred-dollar budget. Nothing has been
reserved.”

## 1:02–1:27 — Exact human authorization

**On screen:** Open authorization, acknowledge the scope, and authorize.

**Voiceover:** “Before any consequential action, a human authorizes this exact
canonical plan hash. The approval is session-bound, cost-bound, action-scoped,
and expires in ten minutes. Change the plan, inventory, browser session, or
approval window, and the action fails safely.”

## 1:27–1:48 — Safe execution

**On screen:** Create simulated reservations and reveal the confirmations.

**Voiceover:** “Now the backend creates the hotel, meeting room, and activity
requests atomically. These reservations are simulated. Retrying returns the
same ledger, so an interruption cannot produce duplicates or a partial booking.”

## 1:48–2:00 — Close

**On screen:** End on the confirmed plan, then a restrained architecture card.

**Voiceover:** “Offsite Captain runs on Cloud Run with Firestore and Vertex AI.
Gemini proposes. Deterministic systems validate. Humans authorize. The backend
acts safely.”

## End-card copy

- Offsite Captain
- A safer operating layer for startup offsites
- Gemini 3.5 Flash · Google ADK · Vertex AI · Cloud Run · Firestore
- All inventory and reservations are simulated
